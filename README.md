# YGO ART LAB — 임시 일러스트 생성기 V1.4

유희왕 커스텀 카드의 **정식 일러스트가 준비되지 않았을 때** 카드 ID별 임시 일러스트를 대량 생성하는 무료 브라우저 도구입니다. 이미지를 카드에 합성하거나 CDB·Lua 파일을 수정하지 않습니다.

**웹앱:** https://bduidohd937-beep.github.io/ygoimeagemaker/

## 기능

- **CDB** (`datas` / `texts`) 또는 **CSV·TXT**에서 카드 ID/이름 불러오기. 카드 ID 직접 입력도 가능
- 심해·우주·화염·기계·유적·자연·성역·그림자·폭풍·설원·사막·독저주 12가지 배경. 테마별 문양과 전사/드래곤/기계/날개/정령/결정/야수/검/눈/촉수 모티브를 절차적으로 합성
- CDB의 `type` 및 `race`에서 몬스터 종류를 추정해 실루엣 자동 선택 (마법·함정은 추상 배경만)
- 카드별 스타일 변경 및 한 장만 랜덤 변형, 전체 스타일·톤·실루엣 종류·해상도·JPG/PNG 설정
- **카드명/ID 검색, 체크박스 선택, 검색 결과 모두 선택, 선택 해제, 카드별/선택 삭제**
- **체크한 카드만 ZIP으로 다운로드**, 현재 한 장 저장, ZIP 생성 진행률·취소
- **설정과 카드 목록, 선택 상태를 이 브라우저에 저장**. 새로고침해도 복원 (브라우저 데이터를 지우면 초기화)
- 파일명 `카드ID.jpg` 또는 `카드ID.png`. 출력은 정사각형 **512·768·1024 px**, 프레임과 효과 텍스트 없음

## 사용 순서

1. CDB/CSV/TXT 업로드 또는 카드 ID와 카드명을 직접 추가합니다. 샘플 3장은 첫 입력 때 자동으로 대체됩니다.
2. 전체 스타일·이미지 주제를 선택하고, 필요하면 미리보기 영역에서 **현재 카드만** 스타일/변형을 조정합니다.
3. 카드 검색과 체크박스로 ZIP에 넣을 카드를 고릅니다. 검색 결과 모두 선택은 **현재 검색 결과**에 적용됩니다. '선택 해제'는 전체 선택을 해제합니다.
4. **선택 카드 ZIP 저장**을 누르면 `카드ID.jpg` 또는 `카드ID.png` 묶음이 내려옵니다. 기존 카드 메이커나 EDOPro 커스텀 이미지 경로에 활용하세요.

CSV/TXT 예시:

```csv
918760001,RS－오리온,cosmos
918760002,RS－세컨드 코너,machine
918760003,RS－그랜드리버설,ocean
```

세 번째 스타일 열은 선택 사항이며 `ocean`, `cosmos`, `ember`, `machine`, `relic`, `bloom`, `divine`, `shadow`, `storm`, `frost`, `desert`, `venom` 중 하나입니다. 최대 400장, 업로드 파일 최대 30MB입니다. ZIP 이미지 총량이 350MB를 넘으면 메모리 과다 사용을 막기 위해 중단하며, 일부 카드 선택 또는 낮은 해상도를 안내합니다.

## 구조와 오픈소스

- `index.html` · `styles.css` · `app.js`: 프레임워크·서버 없는 순수 HTML/CSS/JavaScript Canvas
- CDB 로딩 시 사용하는 [`sql.js`](https://github.com/sql-js/sql.js) v1.13.0은 **MIT 라이선스**의 오픈소스입니다. 최초 로딩 시 CDN에서 JavaScript/WASM 파일을 불러옵니다. 인터넷 접속이 없으면 TXT/CSV/수동 입력은 그대로 작동합니다.
- 생성·ZIP 제작은 브라우저 내부에서 이루어지고 CDB가 서비스 서버로 업로드되지 않습니다. ZIP은 이미지가 이미 압축된 형식이므로 현재는 추가 라이브러리 없이 ZIP 무압축 저장 방식으로 묶고, CRC32 테이블 방식으로 검사값을 계산합니다.
- `fflate` 같은 MIT 압축 라이브러리도 검토했지만, 현재 요구 사항에서는 추가 번들/압축보다 간결한 무압축 ZIP이 적합해 포함하지 않았습니다.
- 이미지 원본은 캐릭터를 정밀하게 생성하는 AI 이미지가 아니라 **실루엣과 추상 패턴으로 구분하는 임시 그림**입니다. Lua 실행·EDOPro 전개 성공을 검증하는 기능은 아닙니다.

## 검증

Chromium 기반 독립 브라우저 테스트에서 카드 검색·선택/해제·삭제·스타일별 미리보기·설정 복원·개별 JPG 저장·선택 ZIP 생성/CRC·CSV 불러오기 통과. 또한 60장(512px JPG) 일괄 ZIP의 모든 파일명과 CRC를 확인했습니다. **실제 CDB-WASM 종단 테스트 및 공개 배포 사이트에서의 사용자 환경 테스트는 별도 확인이 필요합니다.**

로컬에서는 `index.html`을 브라우저로 열 수 있습니다. 브라우저가 WASM을 제한하면 `python -m http.server 8000`을 실행하여 `http://127.0.0.1:8000/`으로 접속하세요.

## V1.3 — 카드군 프리셋 / 선택 카드 일괄 적용

- 무성해, 코스모코드, 바르네크, 아칠리쉬, 천망성역, 심연묘역 프리셋 6종 제공
- 오른쪽 목록에서 **체크한 카드에만** 프리셋이나 배경/중심 모티브/색상 직접 조합 적용
- 직접 조합은 각 항목마다 **기존 유지**를 선택할 수 있으며 개별 설정 해제도 가능
- 미리보기에서 카드마다 배경/모티브/색상을 수정 가능
- 직전 일괄 설정은 탭을 닫기 전 되돌릴 수 있음(1회, 저장되지 않음)
- V1.1의 `localStorage` 저장 키를 그대로 사용하여 기존 카드 목록과 설정 유지. CDB와 Lua 원본은 수정하지 않음

주의: 프리셋은 완성된 일러스트를 가져오는 기능이 아니라 절차적 임시 이미지의 디자인 설정을 일괄 적용하는 기능입니다. 카드명이나 카드군 인식 자동분류가 아니라 사용자가 선택한 카드들을 일괄 처리합니다.

## V1.4 오픈에셋 기반 이미지 합성

- 중심 피사체에 Game-icons 프로젝트의 SVG 30종을 내장합니다. 별도의 AI API나 키가 필요하지 않습니다.
- **일러스트 표현 방식**에서 오픈 SVG 에셋 합성(기본) / 기존 절차 벡터를 선택할 수 있습니다.
- 카드 ID/이름/변형 시드에 따라 같은 모티브 안에서도 다른 SVG를 선택하며, 배경과 색조·크기·회전·발광을 브라우저에서 합성합니다.
- 외부 SVG 로드 오류 시 기존 벡터 방식으로 자동 대체합니다. 미리보기, 개별 저장, 선택 ZIP 모두 같은 이미지를 사용합니다.
- 에셋 출처는 `assets/오픈에셋_출처와_라이선스.md`에 정리했습니다. Icons made by **Lorc and Delapouite**. Available on https://game-icons.net. License: **CC BY 3.0**. 검은 배경 삭제와 합성 변형.
- 기존 브라우저 저장 키(`ygo-art-lab-v1.1`)는 유지하므로 V1.3 카드 목록·설정과 호환됩니다.


## V1.5 — 화풍 연구실 24종 / 프롬프트 자동 생성

- 기존 이미지 목록·CDB·CSV·TXT 불러오기와 임시 이미지 생성 기능은 유지합니다.
- **화풍 연구실**에서 24종 주화풍, 보조화풍, 인물/몬스터/기계/마법 연출, 1:1·3:4·오버프레임용 구도, 조명, 디자인 고정 특성을 조합할 수 있습니다.
- 현재 선택한 카드의 ID·이름을 프롬프트 작성에 가져옵니다. 사용자 정의 설명은 직접 수정·고정할 수 있습니다.
- 결과는 실시간 출력되며 복사·TXT 다운로드, 설정 JSON 내보내기/가져오기를 지원합니다.
- **기존 임시 이미지에 유사 분위기 적용** 버튼은 24종 화풍을 기존 12종 배경·SVG/Canvas 모티브로 매핑하는 동작입니다. AI 이미지 생성 API 호출이 아니며, 고품질 AI 화풍 자체를 재현하는 기능으로 설명하지 않습니다.
- 기존 카드 목록 저장 키(`ygo-art-lab-v1.1`)를 건드리지 않고 프롬프트 설정은 별도 키(`ygo-art-lab-prompts-v1`)에 저장합니다.
- 파일명은 사람이 관리하는 한글 이름을 우선하고, 이미지 출력의 카드 ID 파일명 및 프로그램 소스 파일명은 기존 호환 규칙을 유지합니다.
