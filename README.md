# YGO ART LAB — 임시 일러스트 생성기

유희왕 커스텀 카드 CDB/Lua 테스트 과정에서 정식 원화가 준비되지 않았을 때 사용하는 **임시 일러스트 전용** 웹앱입니다.

- CDB 파일(`datas` / `texts` 테이블)에서 카드 ID·이름·속성을 브라우저에서 읽기
- CSV/TXT 또는 카드 ID 직접 입력 (CDB가 없어도 가능)
- 심해·우주·화염·기계·고대·자연·성역·그림자 테마의 **절차적 추상 이미지** 생성
- 카드별로 서로 다른 결과, 동일한 설정에서는 동일 결과 (시드 기반)
- 개별 PNG/JPG 또는 카드 ID 파일명으로 된 ZIP 일괄 다운로드
- 기본 정사각형 일러스트: 512 / 768 / 1024 픽셀
- 카드 프레임, 몬스터 효과, CDB, Lua **생성/수정 안 함**

## 사용법

1. [웹앱 열기](https://bduidohd937-beep.github.io/ygoimeagemaker/)
2. CDB 업로드 또는 ID/카드명 직접 입력 (샘플 목록은 첫 실제 입력 시 교체됨)
3. 왼쪽에서 테마·해상도·형식을 선택한 뒤 미리보기 확인
4. **현재 이미지 저장** 또는 **전체 ZIP 다운로드**
5. 파일 이름은 `카드ID.jpg` / `카드ID.png`입니다. 기존 카드 제작 도구에 이미지를 연결하세요.

TXT/CSV 예시:

```csv
918760001,RS－오리온,cosmos
918760002,RS－세컨드 코너,machine
918760003,RS－그랜드리버설,ocean
```

세 번째 열은 선택적 스타일(`ocean`, `cosmos`, `ember`, `machine`, `relic`, `bloom`, `divine`, `shadow`)입니다. CDB의 속성을 기준으로 자동 테마를 고릅니다.

## 기술 및 개인정보

정적 HTML/CSS/Canvas JavaScript이며 그림 생성과 ZIP 제작은 모두 클라이언트에서 이루어집니다. 파일을 서버로 전송하지 않습니다. **CDB 읽기 기능만** 외부 CDN의 [`sql.js`](https://github.com/sql-js/sql.js) WASM 라이브러리를 최초 1회 로딩하므로 인터넷 연결이 필요합니다. 라이브러리 로드 실패 시에도 TXT/CSV/수동 입력은 작동합니다.

이미지는 실제 캐릭터 일러스트가 아니라 원형 문양·빛·기하학적 실루엣을 합성한 테스트용 이미지입니다. 게임 엔진의 Lua 동작을 검증하는 기능은 포함하지 않습니다.

로컬 실행: 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다. 로컬 파일에서 브라우저가 WASM 로드를 제한한다면 Python의 `python -m http.server 8000` 등으로 HTTP 실행하세요.
